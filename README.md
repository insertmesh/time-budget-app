# Time Budget

A budgeting app for **time** instead of money: you plan your day in buckets (like envelope budgeting), log what actually happened with one tap, and see where the hours went. It's built around personal limits like recovery time and sleep, for people who find time hard to feel (e.g. ADHD, autism).

**Status:** work in progress. Looking for feedback.

## Try it
- **App:** https://insertmesh.github.io/time-budget-app/app/
- **Overview page:** https://insertmesh.github.io/time-budget-app/

It runs in the browser: one HTML file, no install, no account. Data stays in your browser.
