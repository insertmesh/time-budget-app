Mockup controls (not part of the app)

New in Plans v7

  • Save check when leaving Plans: tapping "Tap" (bottom bar or "see it in the Tap tab") with unsaved changes opens "Save your plan?": Save changes now · Review changes (opens the first changed day) · Revert (back to the last saved plan).
  • App closed with unsaved changes: the same check comes first at the next planning moment (evening "Plan tomorrow", morning prompt). Try it: "Close the app with unsaved plan changes", then "Play this moment".
  • The orange save bar now lists the changed days; each one opens that day.

Earlier (v6)

  • Undo last Plan done: after saving, the bar shows "↶ Undo last Plan done (+ N calendar changes)". One click takes the plan back AND takes those calendar changes back. Only the last save, no history. It disappears as soon as you edit again (then "Undo changes" is back).
  • The time bar stays on screen (Day + Templates): the save bar and the "left to plan" box with the coloured day bar stick to the top while you scroll and change blocks.

Earlier (v5)

  • Plan edits are a draft. Nothing is saved while you edit, calendar changes included. A bar sticks to the top of every Plan page: Undo changes (back to the last saved plan), Reset defaults (back to the templates; themes and calendar dates stay) and Plan done ✓ (saves everything and sends all calendar changes at once). The bar turns orange and lists the waiting calendar changes as soon as something is unsaved.
  • "Push change to calendar" is now "Done changing"; "Add to calendar" only queues. The month's separate "Sync cal" button is gone: Plan done sends. "⟳ Resync" (pulling new dates) stays.
  • The 7-second Undo messages are gone. "Plan ready" (plan ahead) and the late-start "Plan done → back to tapping" also save.
  • Tomorrow entry point (button in the controls, = v9.2's "Adjust tomorrow's plan" on the Sleep tile): opens tomorrow's day plan with the same "Start from" chips and "Plan ready ✓" as planning ahead after the checkout.
  • Late start: you can switch between Auto-adjust, Shift and Keep freely before saving.

Earlier (v4)

  • Exact week + / − with step choice (auto · 15 min · 30 min · 1 h), Auto-fix only spreads what is left over the tiles you did not touch, late-start entry point.

Earlier (v3)

  • Drag to reorder (⠿), fixed = order locked (📌), linked wake-up / bedtime (🔗), two-way calendar buttons, approve new dates, week Auto-fix, Plan ready → straight back to tapping.
